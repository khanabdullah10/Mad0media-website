# Mad O Media — Official Website

> Modern, high-performance website for **Mad O Media**, built with Next.js 15 (App Router), React 19, Tailwind CSS, and Framer Motion.

---

## 🚀 Key Features

- **Next.js 15 (App Router) & React 19**: Server components, static site generation, and optimized client interactivity.
- **Creator Instinct Hero & Client Showcase**: Seamless brand ticker and interactive media components.
- **Interactive Capabilities (3D Cylindrical Wheel)**: Custom-built 3D barrel rotation highlighting key agency disciplines.
- **Powered By Tech Stack Grid**: Interactive grid showcasing core technologies (Meta, Google, Shopify, WordPress, Figma, Adobe, Canva, Razorpay) with dynamic hover animations.
- **Connected Ecosystem & Editorial Statement**: Dynamic scroll animations and interactive case study showcases.
- **Direct Lead Capture**: Integrated AJAX contact form routing to `info@mad0media.com`.
- **Fully Responsive & Accessible**: Optimized across all viewports from mobile to ultra-wide displays.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 15
- **UI & Styling**: Tailwind CSS, PostCSS, Lucide Icons
- **Animation**: Framer Motion, CSS 3D transforms
- **Language**: TypeScript

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (version 18.18 or higher recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/khanabdullah10/Mad0media-website.git

# Navigate to project directory
cd Mad0media-website

# Install dependencies
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the site.

### Building for Production

```bash
npm run build
npm run start
```
